# Graphical abstract reference artwork

`reference.pdf` is the vector graphical abstract from
[jgraving/circstats](https://github.com/jgraving/circstats/blob/main/figures/Graphical%20Abstract.pdf).
`artwork.json` contains its measured paths and text spans in page points.
The renderer uses the PDF to recover the original drawing groups'
opacity and clipping. It preserves the reference drawings outside
panel B's plots and generates those plots from a seeded circular model.

See the [reproduction instructions](../../CIRCSTATS_GRAPHICAL_ABSTRACT.md).
